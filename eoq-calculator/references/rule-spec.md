# EOQ 规则说明

## 输入数据

每条原料采购记录至少包含以下字段：

- `物料编码`
- `物料名称`
- `采购供应商`
- `最小订购量（MOQ）`
- `采购提前期（天）`
- `采购梯度`
- `保质期(days)`（可空）

## 采购梯度解析

脚本支持以下常见格式，多个阶梯可用英文逗号、中文逗号、分号或换行分隔：

- `1000-4999:0.5200`
- `5000-9999:0.4800,10000-29999:0.4500`
- `30000+:0.4200`

解析后按阶梯起始数量从小到大排序。

## 拐点判断

相邻阶梯单价降幅：

`delta_i = (price_i - price_{i+1}) / price_i`

从第二个降幅开始，如果满足：

`delta_i < 0.3 * delta_{i-1}`

则认为在当前阶梯出现性价比拐点，推荐量取该阶梯的起始数量，再与 MOQ 比较取较大值。

如果始终未出现拐点：

- 多阶梯：推荐最大阶梯的起始数量
- 单阶梯：推荐首阶梯起始数量与 MOQ 的较大值

## 短保修正

当 `保质期(days) <= 15` 时：

- 即使存在价格优势，也优先选择更小批量高频采购
- 如果规则计算出的推荐量大于 MOQ，则回落到 MOQ

## 多供应商择优

每个供应商先独立计算推荐量，然后按以下优先级选出最终写表记录：

1. 推荐量对应阶梯的有效单价更低
2. 推荐采购量更小
3. 采购提前期更短
4. 供应商名称字典序更小

## 输出字段

最终只写入一条记录，包含：

- `物料编码`
- `物料名称`
- `采购供应商`
- `最小订购量（MOQ）`
- `采购提前期（天）`
- `采购梯度`
- `最优采购量`
- `是否价格拐点`
- `说明`
