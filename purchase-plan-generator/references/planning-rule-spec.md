# 采购计划规则说明

## 输入

- 毛需求：`物料编码`、`物料名称`、`日期`、`仓库`、`计划数量`
- 库存：`物品编码`、`物品名称`、`仓库`、`到期日期`、`台账`
- 在途：`物品编码`、`仓库`、`要求到货日期`、`计划在途量`
- EOQ：`物料编码`、`物料名称`、`最小订购量（MOQ）`、`最优采购量`、`采购提前期（天）`

## 周期

- 周表固定使用 13 个连续周一
- 第 1 列周日期为本次运行时所在周的周一
- 毛需求和在途日期都会映射到所属周一

## 期初库存

- 仅统计 `到期日期` 为空或 `>= 本周一` 的库存
- 期初库存使用 `台账` 汇总

## 在途

- 仅使用 `计划在途量 > 0`
- 到货日期映射到所属周一

## MRP 计算

- 逐周滚动：`期末库存 = 期初库存 + 在途到货 + 计划到货 - 毛需求`
- 当某周期初可用量不足以覆盖需求时，触发采购
- 采购到货回写到缺口周，采购下单写在 `max(0, 缺口周 - 提前期周数)`
- 若需要在计划开始前下单，采购数量记录在首周，并在报告中标为预警

## 采购量规则

设：

- `X` = 从缺口周开始到库存恢复前所需的累计缺口
- `MOQ` = 最小订购量
- `EOQ` = 最优采购量

规则：

- 当 `EOQ <= MOQ` 时：`采购量 = max(X, MOQ)`
- 当 `EOQ > MOQ` 时：
  - `T = MOQ + 0.3 * (EOQ - MOQ)`
  - 若 `X <= T`，采购量取 `MOQ`
  - 若 `X > T`，采购量取 `max(EOQ, X)`

强制约束：

- 采购量不得小于 `MOQ`
- 采购量不得小于 `X`

## 输出

每个 `(物料编码, 仓库)` 输出 3 行：

- `需求数量`
- `库存数量`
- `采购数量`

所有周列都写整数文本，空值统一写 `0`。
